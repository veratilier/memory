# Optional vector indexing

Disabled unless `EMBEDDING_ENABLED=true` is explicitly configured. The owner requested no external text transmission; do not enable it during deployment.

Configuration: HTTPS `EMBEDDING_URL`, `EMBEDDING_MODEL`, `EMBEDDING_DIMENSIONS` (1..8192), `EMBEDDING_INDEX_VERSION`, optional secret `EMBEDDING_API_KEY`. The tuple identifies an index and changing it rebuilds in the background. The existing maintenance timer and successful authenticated writes process up to eight leased jobs. No new timer is installed.

Originals, source evidence and versions remain in D1. Withdrawn/reviewed records cannot be retrieved. Search embeds only queries and falls back to keywords on failure. Index tests use fake vectors and prove plumbing, not semantic relevance. No model or paid service is selected by this release.

This engine is mirrored with Vesper-web `lib/shared-memory-engine.ts` and `lib/memory-vector-index.ts`; keep their contracts synchronized. Vesper-native exposes owner-scoped pending episode candidates; this website continues to show accepted versioned records.
